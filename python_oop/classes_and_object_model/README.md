# Classes and object model

Python exercises about defining classes and creating objects.

## My first square

`0-square.py` defines an empty `Square` class.

## Square with size

`1-square.py` defines a `Square` class with a private instance attribute for
its size.

## Validating square size

`2-square.py` validates that a square's private size is an integer greater
than or equal to zero.
