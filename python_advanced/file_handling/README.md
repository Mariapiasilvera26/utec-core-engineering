# File handling

Python exercises for reading and writing text files.

## Reading a file

`read_file.py` reads a UTF-8 text file and prints its contents to stdout.

## Writing a file

`write_file.py` writes text to a UTF-8 file and returns the number of
characters written.

## Appending to a file

`append_write.py` appends text to a UTF-8 file and returns the number of
characters added.
