# Exception handling

Python exercises for handling errors while working with lists.

## Safe list printing

`safe_print_list.py` prints up to the requested number of list elements on
one line and returns the number of elements printed.

## Safe integer printing

`safe_print_integer.py` prints a value using integer format and returns
`True` when successful, or `False` when the value cannot be formatted as an
integer.

## Safe integer list printing

`safe_print_list_integers.py` prints integer values among the first `x` list
elements on one line and returns the number printed.

## Safe division

`safe_print_division.py` divides two values safely, prints the result from a
`finally` block, and returns the result or `None` when division fails.

## Raising an exception

`raise_exception.py` defines a function that raises a `TypeError`.
