# Core data structures

Exercises for working with Python lists and other core data structures.

`print_list_integer.py` prints each integer in a list on its own line using the `:d` format specifier.

`replace_in_list.py` replaces an element at a valid index and returns the list unchanged when the index is out of range.

`print_matrix_integer.py` prints each row of integers on its own line with single spaces between values.

`add_tuple.py` adds the first two values of each tuple, treating missing values as zero.
