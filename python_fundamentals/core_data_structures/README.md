# Core data structures

Python exercises for working with lists and other core data structures.

## Printing integers

`print_list_integer.py` defines a function that prints each integer in a list
on its own line using integer format specifier `:d`.

## Printing a matrix

`print_matrix_integer.py` prints each row of integers on its own line, with
single spaces between values.

## Replacing a list element

`replace_in_list.py` replaces an element at a valid index and returns the
original list unchanged when the index is out of range.

## Adding tuples

`add_tuple.py` adds the first two values of each tuple, treating missing
values as zero.

## Finding common set elements

`common_elements.py` returns a new set containing the elements shared by two
sets.

## Updating a dictionary

`update_dictionary.py` adds or replaces a key/value pair and returns the
updated dictionary.
